# 2026-11-03 · 변경 시나리오 정리

수업에서 변경한 시나리오를 정리한다. 저장소의 기획·설계 문서(`01_planning/overview.md` 등)는 변경 전 내용이므로, 시나리오는 이 문서를 기준으로 한다.

프로젝트는 이번 주 금요일(11-06)에 마무리할 예정이다.

## 1. 장소와 표시 장치

| 장소 | 수 | 역할 |
|------|:--:|------|
| Start 지점 | 1곳 | 출발 · 작업 종료 후 복귀 · 마커와 표지판 있음 |
| 상차 장소 | 1곳 | 두 물품 모두 상차 · 컨테이너 2개로 가정 |
| 창고(하차 장소) | 2곳 | 물품별 하차 · 적재 · 표지판으로 구분 |

장소 위치는 현장에서 즉석으로 정한다.

| 표시 장치 | 의미 | 비고 |
|------|------|------|
| LED 적 · 녹 | 실린 물품의 종류 | 빈 차량이면 꺼짐 |
| 7세그먼트 1개 | 실린 물품의 수량(0~9) | 빈 차량이면 0 · 아직 설치 전 |

## 2. 모드 1: 마커-위치 매칭

1. 차량에 색상의 종류만 알려 준다.
2. 차량이 색을 하나씩 라인트레이싱으로 찾아간다.
3. 표지판까지 접근해 어떤 장소인지 확인한다.
4. 색과 장소의 대응을 기록한다.
5. 모든 장소의 색을 파악하면 매핑을 종료하고 Start 지점으로 복귀한다.

매핑 결과는 Raspberry Pi와 GUI 양쪽에 저장하며, GUI에 표시한다.

## 3. 모드 2: 물류 운반

매핑 없이는 이 모드를 진행하지 않는다.

GUI에서 물품 2가지의 운반 수량을 각각 입력하면 차량이 이동하며 상하차를 수행한다. 수량은 두 자리도 가능하며, 한 가지 물품만 운반해도 된다.

- 한 번에 한 가지 물품만 싣고 이동한다.
- 1회 적재량은 최대 9개다. 수량이 9개를 넘으면 최대 9개씩 여러 번 왕복한다.
- 먼저 운반할 물품은 프로그램이 무작위로 정한다. 한 물품을 모두 운반한 뒤 다음 물품을 운반한다.
- 상차와 하차는 1초에 1개씩 처리하며, 그 과정을 7세그먼트와 LED로 표시한다.
- 모든 운반을 마치면 Start 지점으로 복귀한다.

## 4. 장소 도착 절차

두 모드 모두 모든 장소에서 아래 절차를 따른다.

1. 라인트레이싱과 마커 판단으로 해당 장소까지 이동한다.
2. 경로 끝의 정지선을 인식한다.
3. 카메라 각도를 조절해 전방의 표지판을 향하게 한다.
4. 전진하며 표지판에 접근한다.
5. 초음파 센서 값이 약 18cm가 되면 정지한다.
6. 모드 1은 장소를 확인하고, 모드 2는 상차 또는 하차를 진행한다.
7. 작업이 남아 있으면 유턴해 경로로 복귀한다.

장애물은 없는 것으로 한다.

## 5. 모드 2 동작 예시

적 12개, 녹 5개를 입력하고 녹이 먼저 선택된 경우다.

| 순서 | 차량 동작 | LED | 7세그먼트 |
|:--:|------|:--:|:--:|
| 1 | Start 출발 → 상차 장소 도착 | 꺼짐 | 0 |
| 2 | 녹 5개 상차(5초) | 녹 | 0 → 5 |
| 3 | 녹 창고로 이동 | 녹 | 5 |
| 4 | 5개 하차(5초) | 녹 | 5 → 0 |
| 5 | 상차 장소로 이동 | 꺼짐 | 0 |
| 6 | 적 9개 상차(9초) | 적 | 0 → 9 |
| 7 | 적 창고로 이동 | 적 | 9 |
| 8 | 9개 하차(9초) | 적 | 9 → 0 |
| 9 | 상차 장소로 이동 | 꺼짐 | 0 |
| 10 | 적 3개 상차(3초) | 적 | 0 → 3 |
| 11 | 적 창고로 이동 | 적 | 3 |
| 12 | 3개 하차(3초) | 적 | 3 → 0 |
| 13 | Start 복귀 · 작업 종료 | 꺼짐 | 0 |

## 6. 변경 전 문서와 다른 부분

| 항목 | 변경 전 문서 | 변경 후 |
|------|------|------|
| 작업 구성 | 단일 시나리오 | 모드 2개 |
| 색과 장소의 대응 | 고정표 | 모드 1에서 차량이 확인해 매핑 |
| 작업 입력 | `START <n>` 작업 횟수 1~9 | 물품별 운반 수량(두 자리 가능) |
| 대기장소 | 마지막 작업 후 주차 | Start 지점 · 작업 종료 후 복귀 |
| 상하차 조건 | 적재 거리 도달 후 3초 유지 | 표지판 약 18cm에서 정지 후 1초에 1개 처리 |
| 장애물 | 정지 · 재가동 | 없음 |
| 적재 수량 표시 | 없음 | 7세그먼트 1개 |

내용과 다른 부분이나 질문이 있으면 GitHub Issues에 등록한다.
