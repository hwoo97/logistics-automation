# 00_instructor · 담당 교수 전달사항

이 폴더는 담당 교수가 프로젝트 진행 상황을 확인하고 팀에 전달할 내용을 기록하는 곳이다.

## 운영 방식
- 작성자는 담당 교수다. 팀원은 이 폴더의 파일을 수정하지 않는다.
- 전달사항은 날짜별 파일(`YYYY-MM-DD.md`)로 작성하고, 아래 목록에 한 행을 추가한다.
- 이 폴더의 전달사항은 Pull Request 없이 main에 직접 반영한다([팀 협업 안내](../.github/CONTRIBUTING.md)의 예외).
- 새 전달사항은 `git pull`로 받아 확인한다.
- 질문과 회신은 GitHub Issues에 등록한다.
