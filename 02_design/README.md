# 2단계 · 시스템 설계
- hardware/ — GPIO 핀맵(pinmap.md), 브레드보드 배선도, 전원 구성, 부품 배치
- software/ — 상태 머신·물류 처리 알고리즘, ROS 2 패키지·노드·토픽 구조
- communication/ — 블루투스(RFCOMM) 규약: 명령 형식, 영상 프레임 형식, 우선순위
- ai/ — Teachable Machine 클래스 정의, 데이터 수집 계획, TFLite 변환
- track/ — 라인 배치·색, 지점(대기장소·작업장·하차 A/B) 위치, 표지판 위치, 유턴·복귀·주차 경로
- 부품 목록(BOM)과 예산은 이 폴더 바로 아래에 둔다
