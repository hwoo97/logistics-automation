# Teachable Machine 클래스 설계

> 용도: 화물(원/사각형) 인식, 지점 표지판 인식 — `classifier_node`([기능 설계서](../software/functional_design.md) F7)
> 방식: Teachable Machine **이미지 프로젝트** → TensorFlow Lite(양자화) 내보내기 → Pi 5에서 LiteRT(`ai-edge-litert`)로 추론

## 1. 모델 구성

화물과 표지판은 인식하는 순간(상태)이 다르므로 **모델 2개로 분리**한다. 클래스 수가 적을수록 정확도가 높고, 서로 헷갈릴 일이 없다.

| 모델 | 사용 상태 | 클래스 |
|------|-----------|--------|
| `cargo.tflite` | LOAD (작업장 이미지판 앞) | `circle`, `square`, `background` |
| `sign.tflite` | CHECK_SIGN (정지선 앞) | `sign_work`, `sign_drop_a`, `sign_drop_b`, `sign_park`, `background` |

- `background`: 이미지판·표지판이 없거나 일부만 보일 때 → "확정하지 않음"으로 처리해 오판 방지
- 모델 파일은 `ros2_ws/src/agv_bringup/models/`에, 학습 원본 이미지는 `04_unit/08_ai_vision/dataset/`(GitHub 제외)

## 2. 표지판·이미지판 디자인 원칙
- 흰 바탕 + 검은 굵은 도형/글자, 가로세로 약 10cm (크기·높이·거리는 S6·S7에서 확정)
- 표지판끼리 **모양이 확연히 다르게** — 예: 작업장 `W`, 하차 A `A`, 하차 B `B`, 대기장소 `P` 큰 글자 + 테두리 모양을 다르게(원·삼각형·사각형·마름모)
- 화물 이미지판: 검은 원 / 검은 정사각형, 같은 크기·같은 위치
- 마커 색(빨강·초록·파랑·노랑)과 겹치지 않도록 표지판에는 색을 쓰지 않음 (흑백)

## 3. 학습 데이터 수집 계획
- **차량 카메라로 직접 촬영** (실제 추론과 같은 화질·각도) — 팬틸트 SIGN 자세
| 클래스 | 장수 목표 | 변화 조건 |
|--------|:---:|-----------|
| 각 표지판·화물 | 클래스당 200장 이상 | 거리 3단계, 좌우 약간 어긋남, 조명 2가지(형광등·자연광), 약간 기울어짐 |
| `background` | 300장 이상 | 빈 트랙, 벽, 사람 손, 다른 표지판 일부만 보이는 장면 |
- 수집 시점: 표지판은 S6, 화물은 S7 (테스트 트랙 단계와 함께)
- 촬영 도구: 카메라 토픽을 저장하는 간단한 스크립트(4단계에서 작성)

## 4. 전처리 (학습과 추론을 똑같이)
- Teachable Machine은 학습 시 이미지를 **정사각형으로 가운데 자르고 224×224로 축소**한다 → 추론에서도 같은 순서(가운데 정사각 크롭 → 224×224)로 맞춘다
- 입력 값 범위: 내보낸 모델 종류에 따라 다름 — 부동소수 모델은 보통 `픽셀/127.5 − 1`(−1~1), 양자화 모델은 0~255 정수. 내보낸 모델의 입력 형식을 확인해 `TfliteClassifier`에 반영 (S6에서 확인)
- 색 순서: OpenCV는 BGR, 모델은 RGB → 변환 필수

## 5. 판정 규칙 (추론)
- 5프레임 연속 추론 → **신뢰도 0.8 이상인 같은 라벨이 3회 이상**이면 확정
- `background`가 확정되거나 기준 미달이면 "인식 실패" → 화물은 2회 재시도 후 `E_CARGO`, 표지판은 `E_SIGN`
- 표지판이 확정됐는데 기대 목적지와 다르면 `E_SIGN`

## 6. 목표 정확도 (테스트 트랙 통과 기준과 동일)
| 항목 | 목표 | 검증 단계 |
|------|------|:---:|
| 표지판 인식 | 95% 이상 | S6 |
| 화물 인식 | 95% 이상 | S7 |
| 추론 시간 | 1회 200ms 이하 (5프레임 1초 안) | S6 |
