## 4. 구매 요약

| 구분 | 항목 |
|------|------|
| 꼭 구매 | PiCar-R5 키트(없을 경우), Raspberry Pi 5(4GB 이상), microSD, 초음파 센서, LED, 저항, 미니 브레드보드, 점퍼선, 트랙 재료(폼보드·테이프·색지·출력물·받침대) |
| 실물 확인 후 결정 | Pi 5 냉각(키트 포함 여부), 멀티미터(보유 여부) |
| 필요할 때만 | USB 웹캠(카메라 대체), I2C LCD(옵션 기능) |

- 키트 가격만 확인됨: 교재 제외 약 180,000~198,000원. 나머지는 구매처를 정한 뒤 가격을 채운다
