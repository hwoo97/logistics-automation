# GPIO 핀맵 — PiCar-R5 자동차 제어보드

> 출처: 교재 『라즈베리파이5로 구현하는 사물인터넷(IoT)과 인공지능(AI) 자율주행 자동차』 10.5 DC 모터 제어, p.243 "라즈베리파이 자율주행 자동차 제어보드 모터 1~4 연결 회로"
> 표기: BCM GPIO 번호

## DC 모터 (DRV8835 × 2, PHASE/ENABLE 모드)

| 모터 | 드라이버 | 방향(DIR/PHASE) | 속도(PWM/ENABLE) |
|------|----------|:---:|:---:|
| 모터-L1 | DRV8835 #1 | GPIO18 | GPIO19 |
| 모터-L2 | DRV8835 #2 | GPIO20 | GPIO21 |
| 모터-L3 | DRV8835 #1 | GPIO22 | GPIO23 |
| 모터-L4 | DRV8835 #2 | GPIO24 | GPIO25 |

- 바퀴 4개를 **각각 따로** 제어 (모터마다 방향 1핀 + PWM 1핀)
- DIR = 회전 방향(0/1), PWM 듀티 = 속도
- 확인 필요: L1~L4가 차체의 어느 바퀴인지 (좌전·좌후·우전·우후), DIR 값과 실제 전진 방향의 관계 → 4단계 모터 테스트에서 확정

### Pi 5 + Ubuntu 구현 메모
- PWM 핀 19·21·23·25 중 Pi 5 하드웨어 PWM은 GPIO19뿐 → **lgpio 소프트웨어 PWM**으로 4개를 같은 방식으로 제어 (DC 모터 속도 제어에는 충분)
- 권장 PWM 주파수: 1kHz 안팎에서 시작해 소음·토크 보고 조정
- DRV8835 모터 전원 2~11V, 채널당 1.5A → 7.4V 배터리 사용 가능. TT 모터 정격(3~6V)을 넘지 않도록 **듀티 상한 약 70~80%** 로 시작

## 서보 (SG90 팬틸트) — 제어보드 PCA9685 (I2C)

> 출처: 교재 10.8 PCA9685 서보모터 제어, p.257

| 신호 | Pi 핀 |
|------|:---:|
| I2C SDA | GPIO2 |
| I2C SCL | GPIO3 |

- 제어보드 "서보모터" 헤더 1~5번(각 G·V·S 3핀) = PCA9685 출력 채널. 서보 선: 갈색 G, 빨강 V, 주황 S(PWM)
| 서보 | 헤더 번호 |
|------|:---:|
| 팬(좌우) | 확인 필요 (조립 시 꽂은 번호로 확정) |
| 틸트(상하) | 확인 필요 |
- 교재는 `adafruit-circuitpython-servokit`(Blinka) 사용. Ubuntu에서는 I2C 활성화 후 같은 라이브러리 또는 `smbus2`로 PCA9685 직접 제어

## 센서·표시 — **브레드보드로 별도 연결**

핀 배정 (모터 18~25, I2C 2·3, 예약 17과 겹치지 않음) — 배선 방법은 [wiring.md](wiring.md)

| 장치 | GPIO | 헤더 핀 | 비고 |
|------|:---:|:---:|------|
| 초음파 Trig | GPIO5 | 29 | 3.3V 출력으로 HC-SR04 트리거 가능 |
| 초음파 Echo | GPIO6 | 31 | **5V → 3.3V 분압 필수** (1kΩ + 2kΩ) |
| LED 빨강 (원) | GPIO16 | 36 | 전류 제한 저항 330Ω |
| LED 초록 (사각형) | GPIO26 | 37 | 전류 제한 저항 220~330Ω |
| 초음파 전원 | 5V / GND | 2 / 39 | 브레드보드 레일 |

- GPIO17은 교재 서보 회로도에 표시되어 **예약**(PCA9685 OE 가능성) — 용도 확인 전까지 사용 안 함
- 실물 확인 필요: 제어보드 GPIO 헤더에서 위 핀을 브레드보드로 연결할 수 있는지
