# 브레드보드 배선도 — 초음파 센서 · LED · 7세그먼트

> 대상: 키트에 없는 초음파 센서(HC-SR04) 1개, LED 2개(빨강·초록), 7세그먼트 1자리(2026-11-02 추가)를 브레드보드에 올려 제어보드의 GPIO 헤더와 연결
> 표기: GPIO = BCM 번호, 핀 = 40핀 헤더 물리 번호
> 전체 핀맵은 [pinmap.md](pinmap.md)

## 1. 핀 사용 현황 (겹침 방지)

| 구분 | GPIO | 용도 |
|------|------|------|
| 사용 중 | 2, 3 | I2C (PCA9685 서보) |
| 사용 중 | 18~25 | DC 모터 4개 (DIR/PWM) |
| 예약 | 17 | 교재 서보 회로도에 표시(PCA9685 OE 추정) — 제어 없이 서보 동작 확인(2026-10-26), HIGH가 되면 서보가 꺼질 수 있어 다른 용도로 쓰지 않음 |
| 비워 둠 | 0, 1 | HAT 식별용 EEPROM |
| 비워 둠 | 14, 15 | UART (디버그 콘솔용) |
| 비워 둠 | 8, 9 | SPI0 CE0·MISO (남은 여유 핀 — 9는 2026-11-09 7세그먼트 e에서 비움) |
| **새로 배정** | **5, 6, 16, 26** | **초음파 Trig·Echo, LED 빨강·초록** |
| **새로 배정** | **4, 27, 12, 13, 7, 10, 11** | **7세그먼트 a~g** (SPI0·하드웨어 PWM 확장은 포기. e = GPIO7, 2026-11-09 GPIO9에서 옮김) |

- 새로 배정한 4개 핀은 헤더 아래쪽(핀 29~37)에 모여 있고, 바로 옆에 GND 핀(30·34·39)이 있어 배선이 짧다
- 이웃 핀 주의: 핀 35(GPIO19)·38(GPIO20)·40(GPIO21)은 **모터 핀**이다. 점퍼를 꽂을 때 한 칸 밀리지 않게 주의

## 2. 핀 배정

| 장치 | 신호 | GPIO | 헤더 핀 | 연결 |
|------|------|:---:|:---:|------|
| 초음파 HC-SR04 | VCC | — | 2 (5V) | 브레드보드 + 레일 |
| 초음파 HC-SR04 | GND | — | 39 (GND) | 브레드보드 − 레일 |
| 초음파 HC-SR04 | Trig | **5** | **29** | 직결 (3.3V 출력으로 트리거 가능) |
| 초음파 HC-SR04 | Echo | **6** | **31** | **분압 필수**: Echo → 1kΩ → GPIO6, GPIO6 → 2kΩ → GND |
| LED 빨강 (원) | 신호 | **16** | **36** | GPIO16 → 330Ω → LED 긴 다리(+), 짧은 다리(−) → GND |
| LED 초록 (사각형) | 신호 | **26** | **37** | GPIO26 → 220~330Ω → LED 긴 다리(+), 짧은 다리(−) → GND |
| 7세그먼트 | a·b·c·d·e·f·g | **4·27·12·13·7·10·11** | **7·13·32·33·26·19·23** | GPIO → 330Ω → 세그먼트 핀 (부품 데이터시트로 핀 위치 확인) |
| 7세그먼트 | 공통 | — | 25(GND) 또는 17(3.3V) | 공통 캐소드 → GND / 공통 애노드 → 3.3V |

## 3. 배선도

```
 제어보드 GPIO 헤더                          브레드보드
 ┌──────────────────┐
 │ 핀 2  (5V)   ●───┼──────────────────────── + 레일 (5V)
 │ 핀 39 (GND)  ●───┼──────────────────────── − 레일 (GND)
 │                  │
 │ 핀 29 (GPIO5) ●──┼──────────────────────── HC-SR04 Trig
 │                  │                          HC-SR04 VCC ── + 레일
 │                  │                          HC-SR04 GND ── − 레일
 │ 핀 31 (GPIO6) ●──┼──────────┬───────────── (분압 중간점)
 │                  │          │
 │                  │      HC-SR04 Echo ── 1kΩ ──┘
 │                  │          └── 2kΩ ── − 레일
 │                  │
 │ 핀 36 (GPIO16) ●─┼── 330Ω ── LED 빨강(+)  LED 빨강(−) ── − 레일
 │ 핀 37 (GPIO26) ●─┼── 330Ω ── LED 초록(+)  LED 초록(−) ── − 레일
 └──────────────────┘
```

- 분압 결과: Echo 5V × 2k / (1k + 2k) ≈ **3.3V** → Pi 입력 보호
- 1kΩ·2kΩ이 없으면 같은 비율(예: 10kΩ + 20kΩ, 2.2kΩ + 4.7kΩ)도 가능

## 4. 주의 사항
- **GND 공통**: 브레드보드 − 레일은 반드시 헤더 GND 핀에 연결 (Pi·제어보드와 같은 GND)
- **5V는 초음파에만**: LED는 GPIO(3.3V)로 직접 구동. GPIO 핀에 5V를 직접 넣지 않는다
- **7세그먼트 전류**: 세그먼트마다 330Ω이면 약 4mA, 7개 모두 켜도 약 30mA. 저항을 공통 단자에 하나만 달면 켜진 세그먼트 수에 따라 밝기가 달라지므로 세그먼트마다 단다
- **LED 전류**: GPIO 1핀당 약 8mA 이하로. 초록 LED가 너무 어두우면 220Ω으로 낮춤 (순방향 전압이 큰 초록 LED는 330Ω에서 어둡게 보일 수 있음)
- **헤더 접근**: 제어보드의 GPIO 헤더(교재 p.257 기판 그림의 2열 헤더)에 암-수 점퍼선으로 연결 — 실물에서 핀 번호 표기를 먼저 확인
- **주행 중 흔들림**: 브레드보드를 차체에 양면테이프로 고정, 점퍼선은 여유 있게 묶기. 초음파 센서는 차량 정면, 카메라 시야를 가리지 않는 높이에 고정

## 5. 확인 순서 (S0 단계)
1. 전원 끈 상태에서 배선 → 핀 번호를 표와 한 번 더 대조
2. 전원 켜고 LED 2개를 하나씩 켜 보기 (GPIO16, GPIO26), 7세그먼트 0~9 표시
3. 초음파 거리 값 확인 (자 대고 10 / 20 / 30cm)
4. 모터·서보와 동시에 동작시켜 간섭 없는지 확인
