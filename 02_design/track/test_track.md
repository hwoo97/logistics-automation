# 테스트 트랙 설계 — 단계별

> 상태: **확정** (2026-10-26) — 3단계에서 제작, 4단계에서 S0~S10 순서로 검증

> 진행 방식: **단계별 테스트 트랙 제작 → 단위 기능 검증 → 결과를 반영해 실제 트랙 설계**
> 각 단계는 앞 단계 트랙에 구간을 **덧붙이는 방식**(모듈식)이라 테이프·보드를 재사용한다. 마지막 단계가 통합 확인용 I자 트랙이다.
> 모든 방향 전환은 **직각(90°)** 으로 한다 — 곡선·사선 분기 없음.
> **모든 라인은 검정**이고, 분기점의 **모든 갈래**에 그 갈래로 갈 수 있는 **목적지 색 마커**를 붙인다 (아래 "색 마커 규칙").
> 실험 결과는 `04_unit/<번호_기능>/test.md`에 기록하고, 아래 "실제 트랙에 반영할 값"을 채운다.

## 색 마커 규칙
**목적지 색**: 하차 A(원) **빨강** · 하차 B(사각형) **초록** (LED와 같음) · 작업장 **파랑** · 대기장소 **노랑**

각 갈래에는 **그 갈래로 가서 도착할 수 있는 목적지의 색**을 모두 붙인다.

| 분기점 | 갈래 | 도착 가능한 목적지 | 마커 |
|---|---|---|---|
| ① 위쪽 | 하차 A 쪽 | 하차 A | 빨강 |
| ① 위쪽 | 하차 B 쪽 | 하차 B | 초록 |
| ① 위쪽 | 줄기 (아래로) | 작업장, 대기장소 | 파랑 + 노랑 (나란히) |
| ② 아래쪽 | 작업장 쪽 | 작업장 | 파랑 |
| ② 아래쪽 | 대기장소 쪽 | 대기장소 | 노랑 |
| ② 아래쪽 | 줄기 (위로) | 하차 A, 하차 B | 빨강 + 초록 (나란히) |

- 마커 패치: 분기점마다 4장 × 2곳 = **8장**
- **판단 규칙 (예외 없음)**: 분기점에서 멈춰 카메라로 갈래들을 본다 → **목적지 색이 붙은 갈래로** 간다. 들어온 갈래(뒤쪽)는 후보에서 제외
  - 목적지는 상태로 정해짐: 출발·복귀 → 작업장, 적재 후 → 원이면 하차 A / 사각형이면 하차 B, 마지막 하차 후 → 대기장소
- **오류 감지**: 앞쪽 갈래 중 목적지 색이 붙은 갈래가 **정확히 하나**여야 한다. 없거나 둘 이상이면(마커 탈락·오인식) 정지 후 블루투스 알림. 도착 후에는 표지판으로 한 번 더 확인
- **줄기 마커 2개**: 두 색 패치를 갈래 방향과 수직으로 나란히 붙여 한 화면에서 둘 다 보이게 함
- **정지선과 분기점 구분**: 라인이 모두 검정이므로 길이로 구분 — 정지선은 라인 양옆으로 짧게(예: 10cm), 분기점의 가로 라인은 화면 끝까지 이어짐. 분기점 주변 색 마커도 보조 단서
- 마커 크기·분기점 중심에서의 거리·2색 패치 간격은 S4·S5 실험으로 결정

## S0 · 트랙 없이 기초 동작
- 차량을 받침대에 올려 바퀴를 띄운 상태 → 바닥 주행 순서
- 확인: 카메라 영상 토픽, 팬틸트 2축 각도(라인용·표지판용), 모터 4개 방향과 실제 바퀴 위치(L1~L4), 초음파 거리값, LED 2색, 블루투스 명령 수신·영상 전송 속도·지연

## S1 · 직선
```
[출발] ━━━━━━━━━━━━━━━━━━━━━━━━━━━━ (1.5m, 검은 테이프)
```
- 라인 굵기 후보 2종(예: 2cm / 4cm)을 나란히 깔아 비교
- 확인: 라인 중심 추종, 속도별 안정성, 출발·정지 동작

## S2 · 직각 코너
```
                 ┏━━━━━━━━┓
                 ┃        ┃
[출발] ━━━━━━━━━━┛        ┗━━━━━━━━
       (직선)   좌회전  우회전  우회전 …
```
- S1 직선 끝에 90° 코너를 이어 붙임 — **좌회전과 우회전을 모두** 포함 (계단 모양)
- 동작: 라인 주행 → 코너 검출(라인이 화면에서 옆으로 꺾이는 것을 카메라로 인식) → 감속·정지 → **제자리 90° 회전** → 새 라인 재인식 → 주행
- 비교: 회전 방식 2가지 — (a) 좌우 바퀴 반대 방향 제자리 회전, (b) 한쪽 바퀴만 도는 피벗 회전
- 확인: 회전 후 라인 복귀 성공률, 회전 각도 오차, 코너 전 감속 거리, 코너와 코너 사이에 필요한 최소 직선 길이
- 실제 트랙이 직각 위주가 되므로, 곡선 대신 이 값들을 실제 트랙 설계에 반영

## S3 · 정지선
```
[출발] ━━━┃━━━━━━┃━━━━━━┃━━━━ 
         얇음   중간   굵음  (예: 2 / 3 / 5cm)
```
- S1 직선 위에 정지선 3종 부착
- 확인: 굵기별 검출률, 정지 위치 오차, 주 라인과 혼동 여부

## S4 · 색 마커 판별
```
[출발] ━━━━━[빨강]━━━━━[초록]━━━━━[파랑]━━━━━[노랑]━━━━━
            (검은 라인 옆에 마커 패치)
```
- 검은 라인 옆에 4색 마커 패치를 붙이고, 각 마커 앞에서 정지 → 판별
- 줄기용 **2색 나란히 패치**(빨강+초록, 파랑+노랑)도 붙여 두 색을 모두 읽는지 확인
- 크기 후보 2종(예: 4cm / 6cm 정사각형) 비교
- 확인: 색별 판별 정확도, 형광등·자연광 2가지 조명, 여러 프레임 평균 효과 → 불안정한 색은 대체 색(예: 보라·주황)으로 교체

## S5 · 직각 T자 분기점
```
   ━━━━━━━[빨강]━━┳━━[초록]━━━━━━━
                  ┃ [파랑][노랑]
                  ┃ (모두 검은 라인)
                [출발]
```
- 검은 T자 분기의 갈래 3개에 모두 마커 부착 (S10의 ①과 같은 구성) — 좌우를 바꿔 붙여도 동작하는지 함께 확인
- 동작: 줄기 주행 → 분기점 검출(라인이 좌우로 갈라지는 모양) → 감속·정지 → 목적지 색이 붙은 갈래 확인 → 그쪽으로 제자리 90° 회전(S2 회전 재사용) → 주행
- 오류 감지 테스트: 마커 1장을 떼거나 같은 색을 두 갈래에 붙였을 때 정지·알림하는지
- 확인: 원하는 팔 진입 성공률, 분기점 검출 안정성(S2 코너와 구분되는지), 분기점 앞 감속 거리
- 되돌아오는 방향(팔 → 분기점 → 줄기)도 테스트: 분기점에서 줄기 쪽으로 90° 회전
- 가로 바 방향 진입도 테스트 (S10 아래쪽 분기점용): 바를 따라오다 분기점을 **직진 통과**하거나, 줄기 쪽으로 **90° 회전**

## S6 · 지점 확인 (표지판)
```
                    [표지판]
[출발] ━━━━━━━━━┃━━━━  ↑ 거리 d, 높이 h
              정지선
```
- 정지선에서 멈춘 뒤 카메라를 올려 표지판 인식
- 거리(예: 15 / 25 / 35cm)·높이(예: 10 / 20cm)를 바꿔 가며 테스트 → 표지판 위치·크기와 틸트 각도 결정
- Teachable Machine 표지판 클래스 학습 데이터도 이 단계에서 수집

## S7 · 작업장 적재
```
[출발] ━━━━━━━━┃━━━━━━━━━━━[이미지판]
             정지선 + 작업장 표지판
```
- 정지선 정지 → "작업장" 표지판 확인 → 접근 상태 → 초음파 적재 거리 도달 3초 → 원/사각형 인식 → LED
- 확인: 적재 거리 값, 손이나 다른 물체로 인한 오판 여부, 화물 인식 정확도
- 원/사각형 학습 데이터도 이 단계에서 수집

## S8 · 유턴 (막다른 끝)
```
[출발] ━━━━━━━━━━━━┃ ← 정지선 = 라인 끝     (빈 공간 → 회전 여유)
```
- **막다른 끝** = 라인이 거기서 끝나서 더 갈 길이 없는 지점. 실제 트랙에서는 **작업장(이미지판)·하차 지점처럼 갈래 끝에 있는 지점**이 여기에 해당해, 일을 마친 차량이 **180° 돌아서 왔던 라인으로 되돌아가야** 한다
- 동작: 라인 끝 정지선에서 정지 → 제자리 180° 회전(S2의 90° 회전 2번 또는 연속 회전) → 왔던 라인 재인식 → 반대 방향 주행
- 라인 끝 뒤쪽에 차량이 회전할 빈 공간을 두고, 필요한 크기를 측정
- 확인: 성공률, 필요한 공간, 4WD 미끄러짐 → 실제 트랙의 유턴 공간과 방식(제자리 회전 / 후진 후 회전 / 루프형으로 유턴 없애기) 결정

## S9 · 장애물
```
[출발] ━━━━━━━━[장애물]━━━━━━━━
```
- 주행 중 장애물을 놓았다 치우기
- 확인: 정지 거리, 재가동 지연, 적재 상태(접근 상태)와 구분되는지

## S10 · 통합 I자 트랙
```
 [표지판 A] ┃━━━━━━━━━━[빨강]━┳━[초록]━━━━━━━━━━┃ [표지판 B]
  (하차 A) 정지선            ① ┃ [파랑][노랑]     정지선 (하차 B)
                               ┃
                               ┃ 줄기
                               ┃
                               ┃ [빨강][초록]
 [대기장소]┃━━━━━━━━━━[노랑]━┻━[파랑]━━━━━━━━━━┃[이미지판]
  (출발·주차) 정지선        ②                    정지선 (작업장)

 모든 라인 검정 · [색] = 그 갈래로 갈 수 있는 목적지 마커
```
- 구성: 대문자 **I** 모양 — 위쪽 가로 바(하차 A·B), 아래쪽 가로 바(대기장소·작업장), 가운데 세로 줄기. **T자 분기점 2개 + 막다른 끝 4곳**(하차 A, 하차 B, 대기장소, 작업장)
- 대기장소를 **한쪽 끝**에 두어 작업 중 주행 경로에 대기장소가 끼지 않음 → 정지선 "통과/정지" 구분 불필요
- 크기 목표: 약 1.5m × 1.2m (S1~S9 구간 재배치)
- 1사이클 흐름
  1. 대기장소에서 출발 → 아래쪽 분기점 ②를 **직진 통과** → 작업장 정지선·표지판 확인 → 이미지판 접근·적재(초음파 3초)·화물 인식·LED
  2. 180° 유턴 → 분기점 ②에서 줄기 쪽으로 90° 회전 → 위쪽 분기점 ①에서 화물에 맞는 쪽(A 왼쪽 / B 오른쪽)으로 90° 회전
  3. 팔 끝 정지선에서 정지 → 표지판 A/B 확인 → 하차(LED off) → 180° 유턴
  4. 분기점 ①에서 줄기 쪽으로 90° 회전 → 분기점 ②에서 작업장 쪽으로 90° 회전 → 작업장 복귀 (그사이 사람이 이미지판 교체)
  5. 작업 횟수만큼 2~4 반복 → 마지막 하차 후 분기점 ②에서 **대기장소 쪽**으로 90° 회전 → 대기장소 정지선·표지판 확인 → 주차
- 분기점 판단 (색 마커 규칙 적용 결과 — 좌우는 위 배치 기준)
  | 분기점 | 들어오는 방향 | 목적지 | 앞쪽 갈래 마커 | 동작 |
  |---|---|---|---|---|
  | ② | 대기장소에서 (→) | 작업장 | 앞: 파랑 / 왼쪽(줄기): 빨강+초록 | 파랑 → 직진 |
  | ② | 작업장에서 (←) | 하차 A 또는 B | 앞: 노랑 / 오른쪽(줄기): 빨강+초록 | 빨강(또는 초록) → 줄기로 우회전 |
  | ① | 줄기에서 (↑) | 하차 A / B | 왼쪽: 빨강 / 오른쪽: 초록 | 빨강 → 좌회전 / 초록 → 우회전 |
  | ① | 하차 A에서 (→) | 작업장 또는 대기장소 | 앞: 초록 / 오른쪽(줄기): 파랑+노랑 | 파랑(또는 노랑) → 줄기로 우회전 |
  | ① | 하차 B에서 (←) | 작업장 또는 대기장소 | 앞: 빨강 / 왼쪽(줄기): 파랑+노랑 | 파랑(또는 노랑) → 줄기로 좌회전 |
  | ② | 줄기에서 (↓) | 작업장 / 대기장소 | 왼쪽: 파랑 / 오른쪽: 노랑 | 작업 남음 → 파랑 쪽 좌회전 / 마지막 → 노랑 쪽 우회전 |
- 확인: 위 1사이클 + 블루투스 작업 횟수 입력·비상 정지, 두 분기점의 선택 규칙이 상황마다 맞게 동작하는지
- 결과로 실제 트랙의 모든 입력값(라인 굵기, 정지선, 코너·분기점 간격, 마커 크기·위치, 표지판 위치, 유턴 공간, **유턴·복귀·주차 경로**) 확정
