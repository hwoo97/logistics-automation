# 테스트 트랙 설계 — 단계별

> 상태: **확정** (2026-10-26) — 3단계에서 제작, 4단계에서 S0~S10 순서로 검증

> 진행 방식: **단계별 테스트 트랙 제작 → 단위 기능 검증 → 결과를 반영해 실제 트랙 설계**
> 각 단계는 앞 단계 트랙에 구간을 **덧붙이는 방식**(모듈식)이라 테이프·보드를 재사용한다. 마지막 단계가 통합 확인용 I자 트랙이다.
> 모든 방향 전환은 **직각(90°)** 으로 한다 — 곡선·사선 분기 없음.
> **모든 라인은 검정**이고, 분기점의 **모든 갈래 라인 위**에 그 갈래로 갈 수 있는 **목적지 색 마커**를 붙인다 (아래 "색 마커 규칙", 2026-11-06 라인 위로 변경).
> 실험 결과는 `04_unit/<번호_기능>/test.md`에 기록하고, 아래 "실제 트랙에 반영할 값"을 채운다.

## 색 마커 규칙 (2026-11-02 변경)

> **색과 지점의 대응은 트랙을 만들 때 정하고, 차량은 초기 설정에서 알아낸다** (지점마다 색 하나, 4색 모두 다르게). 아래 색은 S10 예시 배치
**목적지 색**: 하차 A(원) **빨강** · 하차 B(사각형) **초록** (LED와 같음) · 작업장 **파랑** · 대기장소 **노랑**

**마커 = 지름 약 2cm 원형 스티커를 라인 테이프 위에** (2026-11-06 변경, 이전: 들어오는 라인 옆 좌우). 분기점에서 나가는 각 갈래 라인 위에 그 갈래로 가는 목적지 색을 붙인다. 들어오는 방향마다 따로 붙일 필요 없음 — 어느 쪽에서 오든 같은 스티커를 갈래 위치로 읽음.

| 목적지 색이 보이는 곳 | 동작 |
|---|---|
| 앞으로 이어지는 라인 위 (center — 분기점 너머 직진 라인, 들어오는 라인) | 직진 (멈추지 않음) |
| 왼쪽 갈래 라인 위 | 좌회전 (그쪽에 갈래 라인이 안 보이면 직진) |
| 오른쪽 갈래 라인 위 | 우회전 (그쪽에 갈래 라인이 안 보이면 직진) |
| 양쪽 갈래 | 직진 (잘못 붙인 경우) |
| 안 보임 | 라인을 따라 계속 주행 |

- 예 (사용자 사진, T자 — 아래에서 올라옴): 직진 라인 위 파랑 = 직진, 왼쪽 갈래 위 빨강·초록 = 좌회전, 들어오는 라인 위 노랑(위에서 내려올 때는 직진 라인)
- 위치: 갈래 라인 위, 분기점 중심에서 약 5~15cm. 회전은 갈래 스티커가 화면 높이 120에 오면 멈춰 판단 → 분기점에 가까우면 "회전 전 전진"을 줄임
- 아래 표는 이전 방식(라인 옆) 배치 기록 — 어느 방향에 어떤 색이 필요한지 참고용

| 분기점 | 들어오는 방향 | 왼쪽 | 오른쪽 | 동작 |
|---|---|---|---|---|
| ② | 대기장소에서 → | 파랑 | 파랑 | 작업장 직진 |
| ② | 작업장에서 ← | | 빨강+초록 | 줄기로 우회전 |
| ② | 줄기에서 ↓ | 파랑 | 노랑 | 작업장 좌회전 / 대기장소 우회전 |
| ① | 줄기에서 ↑ | 빨강 | 초록 | 하차 A 좌회전 / 하차 B 우회전 |
| ① | 하차 A에서 → | | 파랑+노랑 | 줄기로 우회전 |
| ① | 하차 B에서 ← | 파랑+노랑 | | 줄기로 좌회전 |

- 스티커 **12장** (주행 흐름에 쓰는 곳만). 흐름에 없는 직진까지 표시하면 20장
- 위치: 라인 가장자리에서 약 3cm 옆. 두 색은 라인과 나란히 앞뒤로 1cm 이상 띄움
  - **회전 스티커**: 분기점 약 5cm 앞 (초기값 — 전진 시간과 함께 S5에서 결정)
  - **직진 스티커(양쪽 같은 색)**: 분기점에서 **20cm 이상 앞** — 가까우면 줄기에서 다가올 때 같은 색이 건너편에 함께 보여 양쪽으로 읽음 (2026-11-02 시뮬레이션: 줄기에서 ② 파랑을 직진으로 읽어 지나침)
- **오류 감지 한계**: 스티커가 모두 떨어지면 T자는 `LINE_END`로 멈추고, 직진 갈래가 있으면 지나간 뒤 도착지 표지판 확인에서 잡힌다. 직진 스티커 1장만 떨어지면 회전으로 읽어 라인을 못 찾고 `E_LINE`
- **정지선과 분기점 구분**: 라인이 모두 검정이므로 길이로 구분 — 정지선은 라인 양옆으로 짧게(예: 10cm), 분기점의 가로 라인은 화면 끝까지 이어짐

## S0 · 트랙 없이 기초 동작
- 차량을 받침대에 올려 바퀴를 띄운 상태 → 바닥 주행 순서
- 확인: 카메라 영상 토픽, 팬틸트 2축 각도(라인용·표지판용), 모터 4개 방향과 실제 바퀴 위치(L1~L4), 초음파 거리값, LED 2색, 블루투스 명령 수신·영상 전송 속도·지연

## S1 · 직선
```
[출발] ━━━━━━━━━━━━━━━━━━━━━━━━━━━━ (1.5m, 검은 테이프)
```
- 라인 굵기 후보 2종(예: 2cm / 4cm)을 나란히 깔아 비교
- 확인: 라인 중심 추종, 속도별 안정성, 출발·정지 동작

## S2 · 직각 코너
```
                 ┏━━━━━━━━┓
                 ┃        ┃
[출발] ━━━━━━━━━━┛        ┗━━━━━━━━
       (직선)   좌회전  우회전  우회전 …
```
- S1 직선 끝에 90° 코너를 이어 붙임 — **좌회전과 우회전을 모두** 포함 (계단 모양)
- 동작: 라인 주행 → 코너 검출(라인이 화면에서 옆으로 꺾이는 것을 카메라로 인식) → 감속·정지 → **제자리 90° 회전** → 새 라인 재인식 → 주행
- 비교: 회전 방식 2가지 — (a) 좌우 바퀴 반대 방향 제자리 회전, (b) 한쪽 바퀴만 도는 피벗 회전
- 확인: 회전 후 라인 복귀 성공률, 회전 각도 오차, 코너 전 감속 거리, 코너와 코너 사이에 필요한 최소 직선 길이
- 실제 트랙이 직각 위주가 되므로, 곡선 대신 이 값들을 실제 트랙 설계에 반영

## S3 · 정지선
```
[출발] ━━━┃━━━━━━┃━━━━━━┃━━━━ 
         얇음   중간   굵음  (예: 2 / 3 / 5cm)
```
- S1 직선 위에 정지선 3종 부착
- **권장 규격 (2026-11-02 시뮬레이션, 실물 확인 전)**: 가로 폭 = 라인 폭의 **4~5배** (라인 19mm면 약 8~10cm, 라인 중앙에 걸쳐 좌우 대칭), 두께(진행 방향) = 라인 폭의 **1.5~2배** (약 3~4cm). 폭이 3배 이하면 거의 안 잡히고, 8배 이상이면 차량이 옆으로 비켜 있을 때 화면 끝에 닿아 놓친다. 같은 테이프 1겹(두께 1배)도 잡히지만 여유가 적다
- 확인: 굵기별 검출률, 정지 위치 오차, 주 라인과 혼동 여부

## S4 · 색 마커 판별
```
[출발] ━━━━━[빨강]━━━━━[초록]━━━━━[파랑]━━━━━[노랑]━━━━━
            (검은 라인 옆에 지름 2cm 스티커)
```
- 라인 왼쪽·오른쪽에 4색 스티커를 붙이고, 개발자 탭 "MARKER" 측정값으로 색·좌우·화면 높이 확인
- 두 색 앞뒤 배치(빨강+초록, 파랑+노랑)와 양쪽 같은 색(직진 표시)도 확인
- 확인: 색별 판별 정확도, 형광등·자연광 2가지 조명, 주행 중 흐림 → 불안정한 색은 대체 색(예: 보라·주황)으로 교체. 2026-11-02 사진 기준 초록이 가장 약함

## S5 · 직각 T자 분기점
```
   ━━━━━━━━━━━━━━┳━━━━━━━━━━━━━━
            [빨강]┃[초록]
                  ┃ (모두 검은 라인, 줄기 옆에 스티커)
                [출발]
```
- 앱에서 목적지 색을 고르고 출발 → 감속·정지 → 좌우 확정 → 전진 → 제자리 회전 → 라인이 보이면 주행 (S10 ①과 같은 구성). 좌우를 바꿔 붙여도 동작하는지 함께 확인
- 조정: "회전 전 전진"(스티커 위치에 맞춤), "제자리 회전"(안 돌면 올리고 지나치면 낮춤)
- 오류 시험: 스티커를 모두 떼면 `LINE_END`로 멈추는지, 라인이 없는 쪽에 스티커를 붙이면 `E_LINE`으로 멈추는지
- 확인: 원하는 팔 진입 성공률, 정지 위치, 회전 후 라인을 바로 따라가는지
- 되돌아오는 방향(팔 → 분기점 → 줄기)도 테스트: 분기점에서 줄기 쪽으로 90° 회전
- 가로 바 방향 진입도 테스트 (S10 아래쪽 분기점용): 바를 따라오다 분기점을 **직진 통과**하거나, 줄기 쪽으로 **90° 회전**

## S6 · 지점 확인 (표지판)
```
                              [표지판]
[출발] ━━━━━━━━━┃━━━━━━━━━━━━━━━━┫   ← 정지선 너머 라인 끝, 거리 d, 높이 h
              정지선
```
- 정지선 정지 → 라인을 따라 서행(라인 이벤트 무시) → 초음파로 표지판 앞 정지 → 카메라를 올려 표지판 인식 → 카메라 내림 → 유턴 → **되돌아가며 정지선을 멈추지 않고 통과**
- 정지선~표지판 거리(예: 25 / 35 / 45cm)·표지판 높이(예: 10 / 20cm)를 바꿔 가며 테스트 → 표지판 위치·크기, 표지판 앞 정지 거리, 틸트 각도 결정
  - 거리는 **초음파 정지 거리(18cm, 2026-11-06부터 라인 주행 중에도 켜짐) + 10cm 이상 — 약 28cm**(정지선 전에 표지판을 장애물로 보고 멈추지 않게), 그리고 **유턴할 때 정지선이 보이지 않을 만큼**
  - 표지판 앞에서 유턴할 공간이 남는지 함께 확인 (S8)
- Teachable Machine 표지판 학습 데이터도 이 단계에서 수집

## S7 · 상차·하차 표시
- 트랙 없이 개발자 탭 또는 시험 명령으로 상차 n개 → 하차 n개를 실행
- 확인: 7세그먼트가 1초마다 0 → n → 0으로 바뀌는지, 원 = 빨강·사각형 = 초록 LED가 첫 1개에 켜지고 마지막 1개에 꺼지는지, 7세그먼트 `-`(초기 설정)·`E`(오류) 표시

## S8 · 유턴 (막다른 끝)
```
[출발] ━━━━━━━━━━━━┃ ← 정지선 = 라인 끝     (빈 공간 → 회전 여유)
```
- **막다른 끝** = 라인이 거기서 끝나서 더 갈 길이 없는 지점. 실제 트랙에서는 **상차·하차 지점처럼 갈래 끝 표지판 앞**이 여기에 해당해, 일을 마친 차량이 **180° 돌아서 왔던 라인으로 되돌아가야** 한다
- 동작: 라인 끝 정지선에서 정지 → 개발자 탭 **U턴** 버튼 → 제자리 왼쪽 회전 → 왔던 라인 재인식 후 정지 → **출발** 버튼으로 반대 방향 주행. 안 돌면 "제자리 회전" 값을 올리고, 지나치면 낮춤
- 라인 끝 뒤쪽에 차량이 회전할 빈 공간을 두고, 필요한 크기를 측정
- 확인: 성공률, 필요한 공간, 4WD 미끄러짐 → 실제 트랙의 유턴 공간과 방식(제자리 회전 / 후진 후 회전 / 루프형으로 유턴 없애기) 결정

## S9 · 장애물
```
[출발] ━━━━━━━━[장애물]━━━━━━━━
```
- 주행 중 장애물을 놓았다 치우기
- 확인: 정지 거리, 재가동 지연, 표지판 접근 상태와 구분되는지

## S10 · 통합 I자 트랙
```
 [표지판 A] ┃━━━━━━━━━━[빨강]━┳━[초록]━━━━━━━━━━┃ [표지판 B]
  (하차 A) 정지선            ① ┃ [파랑][노랑]     정지선 (하차 B)
                               ┃
                               ┃ 줄기
                               ┃
                               ┃ [빨강][초록]
 [대기장소]┃━━━━━━━━━━[노랑]━┻━[파랑]━━━━━━━━━━┃ [표지판 W]
  (출발·복귀) 정지선        ②                    정지선 (상차 지점)

 표지판은 정지선 너머 라인 끝 (S6에서 정한 거리)

 모든 라인 검정 · [색] = 그 갈래로 갈 수 있는 목적지 마커
```
- 구성: 대문자 **I** 모양 — 위쪽 가로 바(하차 A·B), 아래쪽 가로 바(대기장소·상차 지점), 가운데 세로 줄기. **T자 분기점 2개 + 막다른 끝 4곳**(하차 A, 하차 B, 대기장소, 상차 지점)
- 대기장소를 **한쪽 끝**에 두어 작업 중 주행 경로에 대기장소가 끼지 않음 → 정지선 "통과/정지" 구분 불필요
- 크기 목표: 약 1.5m × 1.2m (S1~S9 구간 재배치)
- 흐름 (지점 도착은 S6 절차: 정지선 → 표지판 앞 → 확인 → 유턴, 유턴 뒤 첫 정지선은 통과)
  - **초기 설정**: 대기장소 표지판을 보고 서 있음 → `SETUP` → 유턴 → 빨강을 따라 하차 A 도착·표지판 A 저장 → 유턴 → 초록 → 하차 B → 파랑 → 상차 지점 → 노랑 → 대기장소 도착(4색 끝, 그대로 정지)
  - **작업 (교수 전달사항 예: 적 12, 녹 5, 녹 먼저)**: `START 12 5` → 유턴 → 상차 장소에서 녹 5개(7세그먼트 0→5, 초록 LED) → 녹 창고에서 5개 하차 → 상차 장소에서 적 9개 → 적 창고 → 상차 장소에서 적 3개 → 적 창고 → Start 복귀·정지 (먼저 운반할 물품은 무작위)
- 분기점 판단 (색 마커 규칙 적용 결과 — 좌우는 위 배치 기준)
  | 분기점 | 들어오는 방향 | 목적지 | 앞쪽 갈래 마커 | 동작 |
  |---|---|---|---|---|
  | ② | 대기장소에서 (→) | 상차 지점 | 앞: 파랑 / 왼쪽(줄기): 빨강+초록 | 파랑 → 직진 |
  | ② | 작업장에서 (←) | 하차 A 또는 B | 앞: 노랑 / 오른쪽(줄기): 빨강+초록 | 빨강(또는 초록) → 줄기로 우회전 |
  | ① | 줄기에서 (↑) | 하차 A / B | 왼쪽: 빨강 / 오른쪽: 초록 | 빨강 → 좌회전 / 초록 → 우회전 |
  | ① | 하차 A에서 (→) | 상차 지점 또는 대기장소 | 앞: 초록 / 오른쪽(줄기): 파랑+노랑 | 파랑(또는 노랑) → 줄기로 우회전 |
  | ① | 하차 B에서 (←) | 상차 지점 또는 대기장소 | 앞: 빨강 / 왼쪽(줄기): 파랑+노랑 | 파랑(또는 노랑) → 줄기로 좌회전 |
  | ② | 줄기에서 (↓) | 상차 지점 / 대기장소 | 왼쪽: 파랑 / 오른쪽: 노랑 | 남은 모양 있음 → 파랑 쪽 좌회전 / 마지막 → 노랑 쪽 우회전 |
- 확인: 초기 설정 매핑이 실제 배치와 같은지, 작업 흐름 + 블루투스 개수 입력·비상 정지, 두 분기점의 선택 규칙이 상황마다 맞게 동작하는지. 색을 바꿔 붙이고 초기 설정을 다시 해도 동작하는지
- 결과로 실제 트랙의 모든 입력값(라인 굵기, 정지선, 코너·분기점 간격, 마커 크기·위치, 표지판 위치, 유턴 공간, **유턴·복귀·주차 경로**) 확정
